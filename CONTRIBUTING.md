# Contribution Guidelines

Thanks for helping make UAE GRC knowledge more open.

## What to add

- Official regulator pages, laws, standards, and guidance relevant to UAE GRC
- Open-source tools useful for UAE compliance work
- High-quality, non-promotional community resources

## What not to add

- Full copies of standards or regulations (link to the official source instead)
- Paywalled, pirated, or leaked material
- Vendor marketing pages or paid course promotions
- Anything containing confidential organizational data

## Format

```markdown
- [Resource Name](https://link) - Short description ending with a period.
```

- Use the official name and the official URL.
- Keep descriptions short and factual.
- Add the entry to the most relevant section.
- One resource per pull request is preferred.

## Before submitting

- Check that the link works.
- Search the list to avoid duplicates.
- Arabic resources are welcome; please add an English description.
